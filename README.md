# Yuchen Liu

Personal website and resume source for Yuchen Liu.

The site is intentionally static and can be served directly by GitHub Pages from the repository root.

## Structure

- `index.html` - personal site
- `styles.css` - visual system and responsive layout
- `script.js` - small hover interaction layer
- `assets/images/` - research figure covers
- `resume/yuchen-liu-resume.tex` - one-page LaTeX resume source

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
